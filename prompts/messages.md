# 案件セッションに送るメッセージ

指揮役が送る。`{…}` を埋めて、各見出しの枠の中をそのまま本文にする。
**「決まり」は毎回末尾に付ける。**案件セッションの会話が要約されると、最初に伝えた決まりが消えることがあるため。

「決まり」に書くのは、**自律実行のときだけ効くこと**に限る。第三者に公開しない・会社の情報を入れない・版を残す・日本語で書く・確認で止まらない、のように Claude を使う上での大前提は、グローバルな指示（`~/.claude/CLAUDE.md`）と second-brain、公開につながる操作の禁止設定（`~/.claude/settings.json`）で、どのセッションでも守られる。ここに繰り返さない。大前提に抜けがあれば、メッセージではなくグローバルな指示の側を直す。

---

## 決まり（共通）

```
――― 自律実行の決まり ―――
【進め方】
・本人は見ていない。本人の代わりに、聞かずに進める。判断基準は second-brain（areas/self/thinking-principles.md・working-with-ai.md・vision.md）
・本人に聞きたいことが出ても止まらない。本人ならこう判断すると想定して進め、このリポジトリの .autopilot/decisions/YYYY-MM-DD.md に1件ずつ書く（見出し「### 何を決めたか」、項目: 場面／聞きたかったこと／想定した答え／根拠（second-brain のどこか。なければ「推測」）／確信度 高・中・低／取り消し方／本人の採点: （未））
・成果物の評価（どの案がよいか、表現が伝わるか、など）も、本人の判断軸を second-brain からトレースして自分で行ってよい。評価した結果と根拠は判断ログに書き、report.md に「本人に確かめてほしい点」として残す
・本人にしかできないこと（本人の耳や目で実物を確かめる、本人が持っている素材を用意する、端末の設定を変える、判断ログを採点する）だけが残ったら、plan.json の waiting_for_user を true にする
・中身の質が最優先。見積もりに合わせて作業を削ったり急いだりしない。見積もりとのずれは記録して次に活かす
・区切り＝本人が覗いたとき「今こうなっている」が分かる状態。自然に選べるなら、小さめの区切りを選ぶ

【区切りでやること】
1. 作り直す前の版はコミットで残す
2. CLAUDE.md の「現在地」を更新し、コミットする（リモートがあれば push）
3. 見て分かる成果物はアーティファクトにしてよい。更新は同じファイルに対して行い、label に版の名前（v1, v2 …と一言）を付ける
4. .autopilot/report.md の先頭に追記する（日時、やったこと2〜3行、コミット、アーティファクトのURL、判断ログの件数、本人に確かめてほしい点、実際にかかった往復数の感覚）
5. 次の .autopilot/plan.json を書いてコミットする
6. このチャットに3行以内の報告を書いて止まる

【指揮役とのやりとり】
・指揮役から「区切りをつけて止まって」と届いたら、新しい作業は始めず、今の作業を一番近い区切りまで進めて【区切りでやること】をして止まる
・.autopilot/plan.json の形: {"updated_at": "UTCのISO時刻", "next_step": "次の区切りまでにやることを一文", "estimate_pct": 5時間枠の何%を使う見込みか（数値）, "waiting_for_user": true/false, "note": "任意"}
・見積もりの参考: 5時間枠1つを使い切ると7日枠が約11%進む。Sonnet でファイルを多く読みながら72往復した作業が5時間枠の約40%だった。Opus は同じ作業でもそれより重い
```

## plan — 次の区切りと見積もりだけ頼む

```
【自律実行】次の区切りと見積もりだけ書いて、作業はせずに止まってください。

このプロジェクトを、本人の代わりに聞かずに進める仕組み（usage-autopilot）を動かしています。枠を配分するために、次の区切りまでに何をやるかと、その見積もりが要ります。

1. CLAUDE.md とこの会話の流れから、次の区切りまでにやることを決める
2. .autopilot/plan.json に書いてコミットする
3. このチャットに、決めた内容を日本語で2行で書いて止まる
{補足}

{決まり}
```

## work — 区切りまで進めてもらう

```
【自律実行】.autopilot/plan.json に書いた次の作業を、区切りまで進めてください。

作業: {next_step}
見積もり: 5時間枠の {estimate_pct}%
{補足}

{決まり}
```

## split — 区切りを小さく分けてもらう

```
【自律実行】次の作業の見積もり（5時間枠の {estimate_pct}%）は、1つの5時間枠に収まりません。

作業: {next_step}

中身の質は落とさずに、途中に置ける区切りを探して、最初の区切りだけを .autopilot/plan.json に書き直し、作業はせずに止まってください。

{決まり}
```

## wrap — 区切りをつけて止まってもらう

```
【自律実行】5時間枠が本人用の余力に近づいたため、区切りをつけて止まってください。

新しい作業は始めず、今の作業を一番近い区切りまで進め、決まりの【区切りでやること】をして止まってください。途中で投げ出す必要はありません。

{決まり}
```
